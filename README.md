# Deteksi Gangguan Kamera Pengawas

## Deskripsi
Proyek akhir Praktikum Pengolahan Citra Digital (PCD) untuk mendeteksi indikasi gangguan kamera pengawas secara real-time menggunakan webcam dan OpenCV.

## Tujuan
Membangun sistem yang dapat memantau kondisi kamera dan memberikan peringatan suara otomatis ketika terdeteksi gangguan visual.

## Fitur
- Deteksi kondisi gambar gelap.
- Deteksi kondisi gambar buram.
- Deteksi kemungkinan kamera tertutup.
- Pemantauan webcam secara real-time.
- Peringatan suara otomatis.
- Pencatatan waktu gangguan.

## Teknologi
- Python
- OpenCV
- pyttsx3

Tahap persiapan dan pengembangan.
